# DJI Market: концепт сравнения комплектаций

Инициативный концепт экрана карточки товара для [dji-market.ru](https://dji-market.ru/).

**Живой прототип:** https://maksim431.github.io/dji-market-kits/

## Проблема
У DJI Mini 5 Pro пять комплектаций от 77 000 до 110 000 ₽, но на карточках только название и цена. Чтобы понять разницу, нужно открыть пять страниц и сверить списки. В отзывах покупатели раз за разом благодарят менеджера за помощь с выбором комплектации: решение уходит из сайта в чат.

## Решение
- Строка «что внутри» на каждой карточке комплекта.
- Блок «За доплату вы получаете» с выгодой и временем полёта.
- Сравнение в шторке: только отличия, скрытие колонок, выбор прямо из таблицы.
- Подбор комплектации за 3 вопроса.

## Как измерить
A/B-тест: конверсия карточки в корзину, доля вопросов о комплектации в чате, доля Fly More Combo в заказах, средний чек.
